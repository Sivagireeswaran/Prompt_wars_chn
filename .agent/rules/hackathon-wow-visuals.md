# Rule: Hackathon Premium Aesthetics
- Typography: Use modern Google Fonts (e.g., 'Inter', 'Outfit', or 'Plus Jakarta Sans') rather than browser defaults.
- Colors: Avoid generic solids. Use curated HSL palettes, subtle dark modes, and modern gradients.
- Micro-interactions: Add smooth CSS hover transitions (0.2s ease), active states, and subtle load animations.
- Polish: Use modern design trends like glassmorphism (backdrop-filter: blur), soft shadows, and clean border-radii (12px to 16px).
- Dynamic State: Include loading skeletons or spinner animations for any simulated asynchronous operations.
