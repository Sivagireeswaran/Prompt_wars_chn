# Workflow: Generate Pitch & Readme
1. Read the codebase to understand the exact features implemented.
2. Author a top-tier `README.md` complete with:
   - Catchy project tagline.
   - The core problem & your solution.
   - Interactive system diagram (using Mermaid).
   - "How we built it" (tech stack, highlights).
3. Generate a 2-minute pitch deck outline and presenter script highlighting:
   - The "Hook" (first 15 seconds).
   - The Live Demo walkthrough points.
   - The business potential / future scope.
